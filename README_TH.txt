KOMI AI 1 — เว็บต้นแบบรุ่นแรก

สิ่งที่มี:
- หน้าเว็บ KOMI AI 1 แบบ responsive
- แชตเดโมที่ตอบตามตัวอย่าง (ยังไม่ใช่ AI ออนไลน์จริง)
- ปุ่มป้อนข้อความด้วยเสียง หากเบราว์เซอร์รองรับ
- PWA manifest และ service worker สำหรับติดตั้ง/แคชเว็บ

วิธีทดสอบ:
1. แตกไฟล์ ZIP
2. นำไฟล์ทั้งหมดไปวางบนเว็บโฮสต์ที่รองรับ HTTPS (เช่น GitHub Pages หรือโฮสต์เว็บของคุณ)
3. เปิด URL บน Android Chrome
4. เลือก “ติดตั้งเว็บแอป” หรือเมนู > “เพิ่มลงในหน้าจอหลัก”

ข้อจำกัด:
- ZIP นี้เป็นเว็บไซต์ ไม่ใช่ APK และไม่ใช่ระบบปฏิบัติการที่แฟลชลงเครื่องได้
- เว็บไม่สามารถเจาะระบบ เปลี่ยน OS หรือควบคุมมือถือทั้งหมดได้
- การเชื่อมต่อ AI จริงต้องมี backend/API ที่ปลอดภัย ห้ามใส่ API key ลับไว้ใน JavaScript ฝั่งเว็บ
- การทำ OS เต็มรูปแบบต้องพัฒนาบน AOSP/Android และต้องมีไดรเวอร์/เฟิร์มแวร์ที่ตรงกับอุปกรณ์
