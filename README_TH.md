# KOMI AI 1 — Device Development Starter (Thai)

ชุดเริ่มต้นสำหรับวางแผนมือถือ KOMI รุ่นใหม่ โดยยังไม่ผูกกับชิปหรือผู้ผลิตรายใด
**นี่ไม่ใช่เฟิร์มแวร์สำหรับแฟลชเครื่องจริง** และยังไม่มีไดรเวอร์/boot image เฉพาะอุปกรณ์

## มีอะไรในชุดนี้
- `docs/ROADMAP_TH.md` — แผนพัฒนาเป็นขั้น
- `docs/HARDWARE_BRIEF_TH.md` — ข้อกำหนดตั้งต้นสำหรับเลือก ODM/ชิป
- `docs/TEST_PLAN_TH.md` — แผนทดสอบจริง
- `web-demo/` — เว็บเดโมหน้าจอ KOMI AI 1 เปิดดูได้ในเบราว์เซอร์
- `docs/SAFETY_AND_RELEASE_TH.md` — ความปลอดภัยและการปล่อยรุ่นทดลอง

## แนวทางที่แนะนำ
1. ทำ UX prototype และทดสอบความต้องการก่อน
2. เลือกฮาร์ดแวร์/ODM ที่มี BSP, kernel source และการอัปเดตความปลอดภัย
3. เริ่มจาก Android/AOSP บนอุปกรณ์พัฒนา/บอร์ดที่รองรับ แทนการเริ่มจากศูนย์
4. สร้าง KOMI Launcher และแอปผู้ช่วย AI เป็นแอป Android ก่อน
5. ค่อยพิจารณา system image เฉพาะเมื่อผู้ผลิตให้เอกสารและสิทธิ์ครบ

## ข้อจำกัดสำคัญ
- ยังไม่ได้เลือกชิป รุ่นเครื่อง หรือ ODM จึงไม่สามารถสร้างไฟล์ APK/เฟิร์มแวร์ที่ติดตั้งกับเครื่องเฉพาะได้อย่างถูกต้อง
- อย่าแฟลช bootloader/system image ที่ไม่ตรงรุ่น เพราะอาจทำให้อุปกรณ์เปิดไม่ติดหรือข้อมูลสูญหาย
- การเชื่อมต่อ AI จริงควรเรียกผ่าน backend ของคุณ อย่าใส่ API key ลับไว้ในแอปหรือเว็บฝั่งผู้ใช้
